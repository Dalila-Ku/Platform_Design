Gestor de Proyectos

Interfaz estática para registrar proyectos y tareas. Los campos están alineados con el esquema de base de datos del equipo y con la idea de una API REST para crear proyectos y tareas.

Configuración de API

El formulario puede funcionar solo como maqueta visual. Si existe backend, se puede enviar la información al endpoint configurado.

Ejemplo: http://localhost:3000/api/v1
Se usará en Authorization si se llena.

Crear proyecto

Formulario basado en la tabla projects: nombre, descripción, estado, prioridad, fechas y dueño.

Corresponde a users.user_id en la base de datos.

Crear tarea

Formulario basado en la tabla tasks. Permite registrar tareas ligadas a un proyecto, hito o subtarea.

Vista previa del payload

La información se muestra en formato JSON para validar que los datos están listos para el backend.
